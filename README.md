# McFluff Blackjack Game ♠️

A simple web-based blackjack game built with HTML, CSS, and JavaScript.

## 💡 Overview
I built this as part of my #100DaysOfCode challenge to practise arrays, objects, conditional statements, and DOM manipulation.

## 🧠 What I Learned
- How to use `for` loops and arrays to render dynamic content.
- How to manage state with variables and functions.
- How to debug efficiently using `console.log()` for visibility.
- How to host a site on Netlify and share it with testers.

## 🧩 Features
- Simulates blackjack card drawing.
- Keeps score and determines win/loss.
- Responsive layout and playful design.

## 🚀 Future Improvements
- Add dealer AI logic.
- Improve betting logic and UX reminders.
- Enhance mobile display.

## 🛠️ Tech Stack
HTML | CSS | JavaScript
